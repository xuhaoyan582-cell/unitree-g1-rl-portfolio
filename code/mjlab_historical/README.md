# Historical mjlab configuration

`g1_custom.py` is a 31-line configuration snapshot preserved in a project conversation on 24 April 2026 (UTC). It was recovered verbatim from the student's posted code; its SHA-256 is `cfc6f458a667b30808964634492d396d3fd2f93e46dfe6625e94ce28de0324d8`.

It illustrates changes to an existing mjlab G1 velocity task: termination angle, removal of a push event, reward weights, and a staged velocity-command curriculum. It imports existing mjlab configuration and registration APIs.

This is an intermediate historical sample, not a reconstructed final project or the code that produced the separate Isaac Gym/MuJoCo demo. Later partial edits, models, and complete logs are not included. It is not supplied as a tested standalone example against current mjlab releases.

Framework: https://github.com/mujocolab/mjlab (Apache-2.0). No upstream mjlab implementation is bundled here.
